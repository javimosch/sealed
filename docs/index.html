sealed

A small self-hosted secrets store with limited agent tokens, built in machin.

Source on GitHub

Experimental. No independent security audit. Not for production secrets.
It helps agents use secrets without accidentally exposing them. It does not stop an agent that is deliberately trying to get them.
# the command gets the secret; recognised forms are hidden in its output
$ sealed exec --env API_KEY=demo/api-key -- sh -c 'echo "key=$API_KEY"'
key=***

# the limit, in one line: transform the value and it gets through
$ sealed exec --env API_KEY=demo/api-key -- sh -c 'printf %s "$API_KEY" | rev'
0987654321-yek-ekaf

What it helps with

  • Keeping keys out of chat transcripts, command arguments, shell history and logs.
  • Storing them encrypted instead of in .env files.
  • Limiting a token to a group of secrets.
  • Asking you before a secret is replaced or deleted through sealed.
  • Recording which token used what.

What it does not protect against

A token holder can get any value its token covers: by transforming it in exec, with render, or by calling the daemon directly. An agent running as your user can also read your token, which covers every secret. Root can read the daemon's memory. All the limits.

What it shows about machin

  • ~1,500lines of MFL
  • ~350lines of C
  • ~200 kBstripped binary
  • < 3 sbuild, on the development machine

One program is both the command-line tool and the daemon. machin's built-ins provide Argon2id, AES-256-GCM, HKDF, HMAC, SQLite, sockets, an HTTP client and JSON. The binary links dynamically to glibc, OpenSSL and SQLite.

Not everything is MFL. Hidden terminal input, running commands, redaction, temporary files, locked memory and process hardening are in a C shim. It is the most security-sensitive code, so review it first.

Try it with a fake secret

Linux x86_64, with machin, a C compiler, and the SQLite and OpenSSL 3 development packages.

git clone https://github.com/javimosch/sealed
cd sealed
./scripts/demo.sh   # throwaway store; you choose a throwaway passphrase
